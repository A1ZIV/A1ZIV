ZEVA311 — Vocabulary Exercise Generator

Что внутри:
1. package.json — настройки проекта.
2. index.html — главная HTML-страница.
3. src/main.jsx — основной код сайта.
4. src/styles.css — стили.
5. zeva311.url — ярлык на будущий сайт.

Как запустить на компьютере:
1. Установить Node.js: https://nodejs.org
2. Открыть папку zeva311_website в VS Code.
3. В терминале написать: npm install
4. Потом написать: npm run dev
5. Открыть ссылку, которую покажет терминал.

Как загрузить на Vercel:
1. Создать аккаунт на Vercel.
2. Загрузить проект через GitHub или Vercel CLI.
3. Название проекта поставить: zeva311
4. Тогда ссылка будет примерно: https://zeva311.vercel.app
